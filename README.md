# ねこログ 🐾

猫の **1日の飲水量** と **おしっこの量** を毎日記録するスマホ向けアプリです。
インストール不要の Web アプリ(PWA)で、ブラウザで開いて「ホーム画面に追加」するとアプリのように使えます。

## 記録のしかた

1. 毎日決まった時間に「残った水の量(ml)」と「取り出したシートの重さ(g)」を量る
2. 量ったら、給水器に決まった量の水を入れ直し、システムトイレのペットシートを新品に替える
3. アプリの「記録」タブに、量った日の日付で入力して保存

アプリが自動で計算します。

- 飲んだ量 = 入れた量 − 残った量 (− 蒸発分の補正)
- おしっこの量 = 使用後シートの重さ − 新品シートの重さ (1 g ≒ 1 ml)

## 機能

- **記録**: 日付ごとに入力。「入れる量」「新品シートの重さ」は設定から自動入力
- **うんち**: 出た時間帯(朝・昼・夜、複数可)または「なし」を記録。量は記録しません
- **下書き保存**: 数値が揃っていなくても途中で保存でき、あとで履歴から開いて続きを入力・確定
- **履歴**: 一覧表示、「編集」で修正、削除。下書きにはバッジ表示
- **グラフ**: 7 / 14 / 30 / 90 日の棒グラフと期間平均、直近7日平均、体重1kgあたりの量、表表示
- **通院**: 診療明細の写真を添付して、日付・病院名・合計金額・メモを記録。今年・今月の病院代、月ごとのグラフ、年ごとの合計を表示
- **設定**: 猫の名前・体重、かかりつけの動物病院、毎日の初期値、蒸発補正
- **データ**: CSV 書き出し(Excel 等で開けます)、JSON バックアップ/復元、全削除
- オフラインでも動作(Service Worker)、ダークモード対応

データはすべて **端末のブラウザ内(localStorage と IndexedDB)** に保存され、外部には送信されません。
機種変更の前などは「設定 → バックアップを保存」で JSON を保存してください。

## 公開のしかた(GitHub Pages)

1. リポジトリを **Public(公開)** にする(無料プランではプライベートリポジトリで Pages は使えません)
2. **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする(初回のみ)
3. `main` ブランチに push すると `.github/workflows/pages.yml` が自動でデプロイします
4. 公開 URL(`https://<ユーザー名>.github.io/catlog/`)をスマホで開き、ホーム画面に追加

ビルド工程はありません。静的ファイルをそのまま配信するだけなので、Netlify や Cloudflare Pages など他のホスティングでも動きます。

## ローカルで試す

```sh
python3 -m http.server 8000
# → http://localhost:8000 をブラウザで開く
```

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面(記録・履歴・グラフ・設定の4タブ) |
| `app.js` | ロジック、保存、グラフ描画、通院記録、CSV/JSON 入出力 |
| `styles.css` | スタイル(スマホ優先、ダークモード対応) |
| `sw.js` | オフライン用 Service Worker。更新時は `VERSION` を上げる |
| `manifest.webmanifest`, `icons/` | ホーム画面追加用のメタ情報とアイコン |

## 注意

飲水量・尿量の「目安」はあくまで一般的な参考値です。体調に関する判断は獣医師にご相談ください。
